# CodeRelayBridge 0.6.37

## 简体中文

- 网页左下角新增“反馈”，位于语言选择左侧，打开对应版本仓库的 GitHub Bug 表单。
- 支持中英文、日夜模式及全部主题；不会自动上传日志、账号、设备或聊天内容。
- 使用说明增加经确认的无个人数据空白界面截图。
- 更新保留现有配对和设置；安装更新仍需用户确认。

## English

- Added Feedback to the left of the panel's language selector, opening the matching edition's GitHub bug form.
- Supports both UI languages and all themes without automatically uploading logs, account, device, or chat data.
- Documentation includes an approved empty-state preview with no personal data.
- Updates preserve pairing and settings; installation still requires confirmation.
