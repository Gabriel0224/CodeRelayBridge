# CodeRelayBridge 0.6.51

## 中文

- 输入区新增可见的“闪电加速”入口。模型速度设置不再因客户端未提供能力而无声消失，会明确说明需要更新客户端或当前模型不支持；仍只显示原 App 实际提供的加速档位。
- 文件、终端、子智能体合并到“扩展”面板，顶部工具重新分组，窄屏及大字号下允许正常换行，不再横向隐藏按钮。打开扩展不会自动创建 SSH 终端。
- 待发送的编辑、引导、删除使用更明显的描边按钮，“修改方向”改为“引导”；不改变原生队列协议。

## English

- Added a visible Fast mode entry next to model settings. Missing client capabilities and unsupported models now show an explanation instead of silently hiding speed settings. Only speed tiers advertised by the original app are offered.
- Combined files, terminals, and subagents under Extensions. Header tools are regrouped and wrap at narrow widths or larger font sizes instead of hiding horizontally. Opening Extensions does not create an SSH terminal.
- Queued Edit, Steer, and Delete actions now use outlined buttons. Queue behavior and native protocol values are unchanged.
